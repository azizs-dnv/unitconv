# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [0.3.0]
### Added
- New categories: pressure, energy, power, angle, frequency, force, fuel economy (including L/100 km).
- More units for length, weight, area, volume, speed, time and data (bit, PB, nautical mile, etc.).
- Many Russian and English aliases (`ккал`, `л.с.`, `мм рт. ст.`, `knot`, etc.).
- `python -m unitconv`, integrity tests for the unit tables, linting with ruff.
- GitHub files: CI, PyPI publishing, issue and PR templates.
- Project fully translated to English.

## [0.2.0]
### Added
- `unitconv` CLI, `Quantity` class, cached currency rates, area/volume/speed/time/data.

## [0.1.0]
- Initial release: length, weight, temperature.
